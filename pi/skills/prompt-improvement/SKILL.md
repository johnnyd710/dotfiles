# Prompt Improvement

Improve the prompt. Do not perform its task unless the user also asks you to.

Make the task deeper, not bigger.

Before rewriting, answer these four questions briefly:

1. What would a top professional do here that the prompt does not ask for?
2. What raw material would they use instead of an already-digested account?
3. Which specific methods and tools would they use?
4. What independent evidence, test, reviewer, or real-world result would show whether the work is right?

Also consider, when useful:

- **Altitude:** What larger outcome should this task enable?
- **Range:** Which other field offers a useful method? Ask for the method, not role-play.

Ask the model to test assumptions against source material and look for blind spots when relevant. Use a stretch goal only when it is measurable and its feasibility can be checked. Do not invent data, access, tools, or validation. Do not let the model certify its own work. Use verbs not nouns.

Return the four brief answers, then a copy-ready prompt. Ask a clarifying question only if missing information blocks a useful rewrite.

Adapted from Felix Rieseberg, [“How to be more ambitious: A tutorial for humans with models”](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/).
